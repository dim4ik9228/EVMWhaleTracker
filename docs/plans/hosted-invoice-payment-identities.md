# Hosted invoice payment identity recovery

- Status: completed
- Date: 2026-10-31
- Summary: one hosted invoice may have several payment identities with different token quotes. An unpaid initial payment must not block the first authenticated fully funded payment.

Preserve the original attempt payment identity and quote. Store authenticated per-payment quote evidence using existing receipt rows and stable `quote:` event keys. Verify each payment against its own frozen quote, the saved invoice/order and USD price, USDTBSC asset/network and actual finished amount. Keep owner-serialized once-only order fulfilment. Additional funded payments remain duplicate evidence; reversal affects only the exact charge's grant. Known-ID retries and audited operator import use the same verification, even with sales disabled. Previously quarantined sibling review evidence is retained and marked processed after successful authenticated reconciliation. No schema migration or manual financial SQL is required.

Regression coverage includes distinct hosted quotes in either arrival order, concurrent funded siblings, winner/duplicate refunds, immutable quote mutation, underpayment including one smallest quoted unit, zero payment, wrong asset/network/order/USD, review recheck, failure after quote persistence and disabled-sales recovery. The initial implementation pass performed no deployment or live financial mutation; subsequent coordinator validation and recovery are recorded below.

The integration pass also protects settled state and paid amount while polling the unpaid primary, including if that primary is later funded as a duplicate and refunded. Only the exact crypto charge owning a grant can reverse the attempt's paid state. User payment history includes positive, currency-bearing applied payments, duplicates, unresolved financial review deposits and refunds. Processed transport/quote evidence and resolved legacy review rows remain durable for operators but are excluded from that history. Presentation regressions cover a recovered payment surrounded by transport and legacy evidence, and retention of financial review/refund states.
